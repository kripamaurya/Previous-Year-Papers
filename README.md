# 📚 MMMUT Previous Year Question Papers (PYQs)

Welcome to the **MMMUT-PYQs** repository! 🎓

This repository contains **Previous Year Question Papers (PYQs)** for students of **Madan Mohan Malaviya University of Technology (MMMUT)**. The papers are organized **semester-wise** and **subject-wise** to make exam preparation easier.

## 📂 Repository Structure

```
MMMUT-PYQs/
│
├── 1st-Year/
├── 2nd-Year/
├── 3rd-Year/
└── 4th-Year/
```

Each year contains subject-wise folders with available Mid-Sem and End-Sem question papers.

## ✨ Features

- 📄 Previous Year Question Papers
- 📚 Semester-wise Organization
- 📁 Subject-wise Folders
- 🚀 Easy Navigation
- 🤝 Open for Contributions
